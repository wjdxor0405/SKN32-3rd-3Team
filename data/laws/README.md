# data/laws — 법령 원문 보관 폴더

`python -m scripts.seed_laws` 가 이 폴더의 파일을 읽어
`documents` 테이블에 `source_type="law"` 로 적재한다.

## 지원 형식

| 형식 | 처리 |
|---|---|
| `.txt` / `.md` | UTF-8(실패 시 cp949)로 읽음 |
| `.pdf` | pypdf 추출 → **머리말·꼬리말·페이지번호 자동 제거** → 줄바꿈 정리 |

`README.md` 와 `_` 로 시작하는 파일은 무시된다.

## 규칙

- **파일명이 곧 문서 제목**이 된다. 답변에서 "자원순환기본법 제3조에 따르면…"
  처럼 인용되므로 **정식 법령명**을 쓸 것.
- 조문은 `제1조(목적)` 형식을 지킬 것. 이 패턴 기준으로 조문 단위 청킹이 이뤄진다.
- 적재 시 **인식된 조문 수가 출력**된다. `조문 0개` 경고가 뜨면 추출이 실패한 것이므로
  파일을 확인할 것.

## 실제 조문 구하는 법

1. 국가법령정보센터(law.go.kr)에서 법령 검색
2. **본문 복사 → txt 저장을 권장** (PDF보다 깔끔하다)
   PDF 다운로드도 그대로 넣으면 자동 정제된다.
3. `python -m scripts.seed_docs` 실행

## PDF가 잘 안 될 때

| 증상 | 원인 · 해결 |
|---|---|
| `조문 0개` 경고 | 조문 형식이 다르거나 추출 실패. 텍스트로 복사해 저장 |
| `텍스트를 추출하지 못했습니다` | 스캔 이미지 PDF. OCR 필요하거나 다른 형식으로 재수집 |
| 머리말이 남음 | 페이지가 1장뿐이면 반복 탐지가 안 된다. 수동 삭제 |

## HWP 파일이라면

pypdf로 읽을 수 없다. 아래 순서로 처리한다.

1. 같은 자료의 **PDF·HTML 버전이 있는지 먼저 확인** (대부분 있다)
2. 한컴오피스에서 열어 **PDF 또는 TXT로 다른 이름 저장**
3. 변환 방법을 전처리 문서에 기록 (제출물)
