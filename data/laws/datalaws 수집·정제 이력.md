## 주의
- 별표 1은 PDF 표를 재구성한 것이므로 시연 전 law.go.kr 원문과 대조 필수
- 두 파일 모두 최종적으로 law.go.kr 현행 조문과 대조 후 사용할 것
- 기존 data/laws/자원순환기본법.txt 는 삭제하고 폐기물관리법.txt 로 교체할 것
- 파일 교체 후 python -m scripts.seed_docs 재실행 필수

- 자원재활용법 제13조는 2026.8.20.에 개정판이 시행됨(지자체의 지침 준수가 의무화되는 방향). 해당 일자 이후 재수집·재시드 권장
- 자원재활용법은 PDF 줄바꿈 병합 과정에서 단어 중간에 공백이 남은 곳이 일부 있음(예: "함 으로써") — 검색 품질에는 영향 미미하나 인용문 표시 시 참고
- 폐기물관리법 시행령은 2025.10.1. 부처명 개정(환경부→기후에너지환경부) 이전 판일 수 있음 — 실질 내용 동일하나 시연 전 law.go.kr 공포번호 대조 권장
- 자원재활용법 시행령 별표 2(폐기물부담금 산출기준)·별표 6(재활용기준비용)의 금액은 원문 표 그대로 옮겼으나, 매년 물가연동지수가 곱해지는 구조이므로 시연 시점 실제 부과액과는 차이가 있을 수 있음(구조 설명용으로만 활용)
- 폐기물관리법 시행규칙은 이번 5건 중 가장 방대한 문서라 별표를 전부 제외했다. 별도 요청 시 별표 4(폐기물 세부분류 코드)나 별표 21(행정처분기준) 등 특정 별표만 추가 발췌 가능
- 분리배출 표시에 관한 지침(현행 환경부고시 제2025-165호) 및 순환경제사회 전환 촉진법(본법)은 law.go.kr·미러 사이트 모두 자동 접근이 차단되어 미확보. 수동 복사 필요
