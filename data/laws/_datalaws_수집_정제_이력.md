## 작업 지시 (필수)

- 파일 추가·교체 후 `python -m scripts.seed_docs` 재실행 필수. 시드 출력의 조문 인식 개수를 위 표의 검증란(99·16·86·64·66·140·1·8·52)과 대조할 것. '조문 0개' 경고가 뜨면 포맷 문제이므로 파일 확인
- 재시드 후 `python -m scripts.eval_retrieval` 골든셋을 실행하여 FAIL 문항이 없는지 확인하고 결과를 본 문서에 기록할 것
- **`data/guide/` 폴더 삭제 필요**: `data/guides/`와 동일 파일이 중복 존재. 시드 스크립트는 `config.py`의 `GUIDES_DIR`(= `data/guides`)만 읽으므로 `data/guide/`는 잔재임 (zip으로는 삭제를 전달할 수 없어 직접 삭제해야 함)
- (완료) data/laws/README.md의 시드 명령 `scripts.seed_docs` 표기 확인 — 현행 README 정상
- (완료) 기존 data/laws/자원순환기본법.txt 삭제 및 폐기물관리법.txt 교체 — 2026-08-02 반영 확인
- (완료) 미확보였던 분리배출 표시에 관한 지침·순환경제사회 전환 촉진법 2건 — 2026-08-03 수동 수집으로 확보
- (완료) 공백 오류 일괄 정리 및 시행규칙 헤더 중복 제거 — 2026-08-03 v2 반영, 조문 수 보존 검증 완료
