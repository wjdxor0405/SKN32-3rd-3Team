## 작업 지시 (필수)

- 파일 추가·교체 후 python -m scripts.seed_docs 재실행 필수. 시드 출력의 조문 인식 개수를 위 표의 검증란(99·16·86·64·66·140·1·8·52)과 대조할 것. '조문 0개' 경고가 뜨면 포맷 문제이므로 파일 확인
- data/laws/README.md의 시드 명령이 scripts.seed_laws로 잘못 표기되어 있음 — scripts.seed_docs로 수정할 것. "샘플·테스트 파일 삭제" 안내도 이미 처리된 내용이므로 정리 권장
- (완료) 기존 data/laws/자원순환기본법.txt 삭제 및 폐기물관리법.txt 교체 — 2026-08-02 반영 확인
- (완료) 미확보였던 분리배출 표시에 관한 지침·순환경제사회 전환 촉진법 2건 — 2026-08-03 수동 수집으로 확보

## 주의 (시연 전 확인)

- 재활용가능자원의 분리수거 지침 별표 1은 PDF 표를 재구성한 것이므로 시연 전 law.go.kr 원문과 대조 필수
- 모든 파일은 최종적으로 law.go.kr 현행 조문과 대조 후 사용할 것
- 자원재활용법 제13조는 2026.8.20.에 개정판이 시행됨(지자체의 지침 준수가 의무화되는 방향). 해당 일자 이후 재수집·재시드 권장 — 시연이 8.20. 이후라면 사실상 필수
- PDF 줄바꿈 병합 관련 알려진 한계: 자원재활용법은 단어 중간에 공백이 남은 곳이 일부 있음(예: "함 으로써"), 반대로 분리배출 표시 지침·순환경제사회법은 어절 경계 공백이 소실된 곳이 일부 있음(예: "포장재가사용된", "매년1회"). 검색 품질에는 영향 미미하나 인용문 표시 시 참고
- 폐기물관리법 시행령은 2025.10.1. 부처명 개정(환경부→기후에너지환경부) 이전 판일 수 있음 — 실질 내용 동일하나 시연 전 law.go.kr 공포번호 대조 권장
- 자원재활용법 시행령 별표 2(폐기물부담금 산출기준)·별표 6(재활용기준비용)의 금액은 원문 표 그대로 옮겼으나, 매년 물가연동지수가 곱해지는 구조이므로 시연 시점 실제 부과액과는 차이가 있을 수 있음(구조 설명용으로만 활용)
- 폐기물관리법 시행규칙은 가장 방대한 문서라 별표를 전부 제외했다. 별도 요청 시 별표 4(폐기물 세부분류 코드)나 별표 21(행정처분기준) 등 특정 별표만 추가 발췌 가능
- 자원재활용법_시행규칙_발췌.txt의 별표 7 수치는 표를 문장형으로 재구성한 것이므로 수치 인용 시 law.go.kr 원문 대조 권장
- 분리배출 표시에 관한 지침의 별표(표시 도안)는 이미지라 미수록 — 도안 관련 질의는 텍스트 검색으로 답변 불가함을 인지할 것
- 순환경제사회 전환 촉진법(제21381호, 2026.2.19.)은 수집 시점(2026-08-03) 기준 law.go.kr 표시 현행판이나, 이후 개정 여부는 시연 직전 재확인 권장
