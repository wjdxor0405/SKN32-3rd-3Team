# 특수 배출 가이드 3종 추가 — 적용 안내

작성 기준일: 2026-08-03. 레포 루트 기준 경로 구조이며, `data/guide/`에 신규 파일 3개가 추가된다(기존 파일 덮어쓰기 없음). ※ guide 폴더 통일 패치가 아직 미적용이면 압축 해제 후 파일을 `data/guides/`로 옮길 것.

## 포함 파일 (3개, 모두 신규·common)

| 파일 | 내용 | 검증 |
|---|---|---|
| `[가이드]_공통_대형폐기물_배출절차.txt` | 신고→수수료→배출 3단계 절차, 품목별 유의사항. 수수료 금액은 지자체별 상이하므로 절차만 수록 | 섹션 4·품목 블록 7, region=common |
| `[가이드]_공통_폐가전_무상방문수거.txt` | E-순환거버넌스(1599-0903) 대상 품목, 신청 채널, 수거 거부 사례, 소형가전 대안 | 섹션 5·품목 블록 5, region=common |
| `[가이드]_공통_유해폐기물_배출.txt` | 폐의약품(수거함·우체통, 약 종류별), 폐건전지, 폐형광등, 기타 | 섹션 5·품목 블록 5, region=common |

3개 모두 레포 청킹 정규식(SECTION_HEADER·ITEM_HEADER)과 REGION_MAP('공통'→common) 인식을 검증했다. 코드 수정은 필요 없다.

## 작성 원칙 (유지관리용 기록)

- 지자체마다 다른 값(대형폐기물 수수료, 이불 분류, 깨진 형광등 처리 등)은 수치를 넣지 않고 "지자체 확인" 안내로 처리 — 오답변 방지
- 시점 변동 정보(전화번호, 서비스 범위)는 문서 머리에 작성 기준일 명시
- 출처: E-순환거버넌스 공식 안내, 환경부 정책브리핑, 서울시·세종시 등 지자체 안내 페이지(공공누리)

## 적용 순서

- [ ] 1. 압축 해제로 3개 파일 추가 (guide 통일 미적용 시 `data/guides/`로 이동)
- [ ] 2. `python -m scripts.seed_docs` 재시드 → 가이드 문서 수가 4→7로 늘었는지 확인
- [ ] 3. 아래 골든셋 문항을 RAG 담당에게 전달하여 `eval_retrieval.py`에 추가 후 실행
- [ ] 4. 커밋 (권장 메시지: `가이드 추가: 대형폐기물·폐가전 무상수거·유해폐기물(common) 3종`)

## 골든셋 문항 초안 (RAG 담당 전달용)

```python
# D. 특수 배출 가이드형 (2026-08-03 신규 3종 대상)
("D1", "장롱 버리려면 어떻게 해야 해?", None,
 {"expect_title": "대형폐기물", "expect_content": "신고"}),
("D2", "냉장고 버릴 때 돈 내야 해?", None,
 {"expect_title": "무상방문수거", "expect_content": "1599-0903"}),
("D3", "선풍기 하나만 버리고 싶은데 무상수거 되나?", None,
 {"expect_title": "무상방문수거", "expect_content": "소형가전"}),
("D4", "먹다 남은 약은 어디에 버려?", None,
 {"expect_title": "유해폐기물", "expect_content": "폐의약품"}),
("D5", "물약도 우체통에 넣어도 돼?", None,
 {"expect_title": "유해폐기물", "expect_content": "우체통에는 넣지 말"}),
("D6", "다 쓴 건전지는 어떻게 버려?", None,
 {"expect_title": "유해폐기물", "expect_content": "전용 수거함"}),
```
※ expect 필드명·형식은 기존 eval_retrieval 골든셋 규약에 맞춰 조정 필요.
